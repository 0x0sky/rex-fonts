# ReX font modification log

## ReX Math

Source font: `master/STIX2Math.otf` (`STIX Two Math`, version 2.00 b137).

Generated font: `out/stix2/rex-stix2.otf` (`ReX Math`).

The source font is distributed under the SIL Open Font License 1.1. Its
original license document is retained verbatim at
`master/STIX_2.0.0_license.pdf`.

ReX modifies the source font by exposing otherwise inaccessible math glyphs
through Private Use Area CMAP entries. Because this changes the font binary,
the generated font is treated as a Modified Version. Its user-facing family,
full and PostScript names are changed to a distinct ReX identity. The source
copyright, trademark, designer and license records remain intact.

The ReX naming change is intentionally limited to identity metadata. It does
not claim authorship of the underlying STIX glyph designs and does not use
the original project or its authors to endorse the modified font.
